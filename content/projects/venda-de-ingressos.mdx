    ## Visão geral

    Projeto de estudo de venda de ingressos com arquitetura orientada a eventos, dividido em serviços independentes que se comunicam por mensageria assíncrona.

    ## Arquitetura

    O sistema é organizado em módulos distintos:

    - **venda-ingressos** — serviço que recebe os pedidos e publica eventos de venda (produtor)
    - **processamento-vendas** — serviço que consome os eventos e processa cada venda (consumidor)
    - **kafka** — infraestrutura de mensageria que desacopla os dois serviços

    ## Destaques

    - Comunicação assíncrona entre produtor e consumidor via Apache Kafka
    - Serviços em Java com Spring Boot
    - Desacoplamento que permite escalar e evoluir cada etapa isoladamente
    - Fluxo resiliente a picos de demanda

    ## Contexto

    Repositório público no GitHub, focado em praticar mensageria e padrões de sistemas distribuídos e orientados a eventos.
  en: |
    ## Overview

    Study project for ticket sales with an event-driven architecture, split into independent services that communicate through asynchronous messaging.

    ## Architecture

    The system is organized into distinct modules:

    - **venda-ingressos** — service that receives orders and publishes sale events (producer)
    - **processamento-vendas** — service that consumes the events and processes each sale (consumer)
    - **kafka** — messaging infrastructure that decouples the two services

    ## Highlights

    - Asynchronous communication between producer and consumer via Apache Kafka
    - Java services with Spring Boot
    - Decoupling that allows scaling and evolving each stage independently
    - Flow resilient to demand spikes

    ## Context

    Public GitHub repository focused on practicing messaging and distributed, event-driven system patterns.
