    ## Sobre o projeto

    Este é o próprio site que você está visitando. Ele reúne meu portfólio, a página sobre mim e um blog para publicar estudos técnicos, com suporte a português e inglês.

    ## Arquitetura

    - App Router do Next.js com geração estática das páginas (`generateStaticParams`)
    - Conteúdo desacoplado do código: projetos e posts vivem como arquivos MDX versionados em `content/`
    - Rotas bilíngues (`/pt`, `/en`) com `next-intl` e troca de idioma preservando a rota

    ## Conteúdo e blog

    - Blog em MDX com frontmatter, tempo de leitura e índice automático
    - Syntax highlighting via Shiki
    - Tema claro/escuro com `next-themes`

    ## Qualidade e segurança

    - Camada de segurança dedicada: validação de slug, proteção contra path traversal e bloqueio de URLs com schemes perigosos, com testes unitários (Vitest)
    - Cabeçalhos de segurança endurecidos (CSP, HSTS, X-Frame-Options, Permissions-Policy)
    - Pipeline de CI com lint, type-check e testes via GitHub Actions
    - `sitemap.xml` e `robots.txt` gerados dinamicamente

    ## Deploy

    Deploy automático na Vercel a cada push na branch `main`.
  en: |
    ## About the project

    This is the very site you are visiting. It brings together my portfolio, the about page, and a blog for technical study notes, with Portuguese and English support.

    ## Architecture

    - Next.js App Router with static page generation (`generateStaticParams`)
    - Content decoupled from code: projects and posts live as versioned MDX files under `content/`
    - Bilingual routes (`/pt`, `/en`) with `next-intl` and language switching that preserves the current route

    ## Content and blog

    - MDX blog with frontmatter, reading time, and an automatic table of contents
    - Syntax highlighting via Shiki
    - Light/dark theme with `next-themes`

    ## Quality and security

    - Dedicated security layer: slug validation, path-traversal protection, and blocking of URLs with dangerous schemes, with unit tests (Vitest)
    - Hardened security headers (CSP, HSTS, X-Frame-Options, Permissions-Policy)
    - CI pipeline with lint, type-check, and tests via GitHub Actions
    - Dynamically generated `sitemap.xml` and `robots.txt`

    ## Deploy

    Automatic deployment on Vercel on every push to the `main` branch.
